# Play-KSH: Casino E-Sports

Aplicación web (HTML/JS) empaquetada en APK para la gestión y pronósticos de competiciones de e-sports.

## Características principales
* Organización de llaves de torneos y emparejamientos.
* Sistema de recompensas y pronósticos para partidas competitivas (e-soccer, torneos por eliminación, etc.).
* Interfaz optimizada para dispositivos móviles Android.
